01
Khởi Đầu

Tạo Tài Khoản GitHub Mới (Nếu Chưa Có)

GitHub giống như "sổ đỏ trực tuyến" lưu trữ toàn bộ trang web của bạn an toàn trọn đời.

1

Mở trình duyệt web và truy cập vào trang đăng ký tài khoản GitHub:

https://github.com/signup
2

Nhập Email của bạn, tạo Mật khẩu và đặt Tên tài khoản (Username) (ví dụ: trinhan-ai).

3

Mở hộp thư Email để lấy mã xác thực 6 chữ số GitHub gửi về và nhập vào màn hình. Vậy là bạn đã có tài khoản GitHub chính chủ!

🖼️ Minh Họa Màn Hình Đăng Ký GitHub:

"Welcome to GitHub! Let's begin the adventure"

Enter your email: email_cua_ban@gmail.com

✓ Đăng ký hoàn toàn miễn phí và bảo mật tuyệt đối

02
Nhân Bản 1-Click

Sao Chép (Fork) Dự Án Trịnh An Về GitHub Của Bạn

Không cần tải code về máy tính! Bạn chỉ cần bấm 1 nút là toàn bộ trang web được sao chép sang tài khoản của bạn.

1

Sau khi đã đăng nhập GitHub mới, bạn hãy mở đường link dự án gốc của Tuấn:

https://github.com/tuangemini/Trinh-An-Chia-Se
2

Nhìn lên góc trên cùng bên phải màn hình, bấm vào nút 🍴 Fork.

3

Màn hình hiện ra bảng xác nhận, bạn giữ nguyên tên hoặc đổi tên theo ý thích, rồi bấm nút xanh: "Create fork".

🖼️ Vị trí nút Fork trên trang GitHub:
tuangemini / Trinh-An-Chia-Se
👁️ Watch
⭐ Star
👉 BẤM VÀO ĐÂY: 🍴 Fork

Ngay sau khi bấm Create Fork, toàn bộ trang web đã chính thức thuộc về tài khoản GitHub của bạn!

03
Phát Sóng Trực Tuyến

Bật Tính Năng GitHub Pages Để Trang Web Hoạt Động

Chỉ với 2 lần click chuột, trang web của bạn sẽ được xuất bản lên Internet miễn phí trọn đời!

1

Tại kho lưu trữ mới của bạn, bấm vào thẻ ⚙️ Settings (Cài đặt) ở thanh ngang phía trên.

2

Nhìn sang cột menu bên trái, tìm và bấm vào mục 📄 Pages.

3

Tại mục Build and deployment:

  • Ô Branch đầu tiên: Chọn main
  • Ô thư mục thứ hai: Giữ nguyên /(root)
  • Bấm nút Save (Lưu).

⚠️ Lưu ý về Tên Miền (Domain):

- Nếu bạn muốn dùng tên miền riêng trinhan.life: Hãy giữ nguyên file CNAME.
- Nếu bạn muốn dùng đuôi miễn phí của GitHub (dạng https://tên-bạn.github.io/tên-repo): Hãy bấm vào file CNAME và bấm icon thùng rác để xóa file CNAME này đi nhé!

🖼️ Minh Họa Cài Đặt GitHub Pages:
Branch: [ main ▼ ] Folder: [ /(root) ▼ ] Save
✓ Your site is live at: https://trinhan.life (hoặc github.io)
04
Chìa Khóa Kết Nối AI

Tạo Mã API Key (GitHub Personal Access Token)

Mã Token này là "chìa khóa thần kỳ" cho phép trợ lý AI (Gemini Spark) thay mặt bạn tự động sửa web, đăng bài và upload ảnh.

1

Bấm trực tiếp vào đường link tạo mã Token sau để đến ngay màn hình cài đặt:

https://github.com/settings/tokens/new
2

Điền thông tin trong biểu mẫu tạo Token:

  • Note: Điền Gemini Spark Website Manager
  • Expiration (Thời hạn): Chọn No expiration (Không bao giờ hết hạn) để không phải tạo lại.
  • Select scopes (Phân quyền): Tích chọn vào ô:
    ☑️ repo (Full control of private repositories)
3

Cuộn xuống cuối trang và bấm nút xanh: "Generate token".

⚠️ QUAN TRỌNG: Màn hình sẽ hiện ra một đoạn mã bắt đầu bằng chữ ghp_.... Hãy bấm nút Copy và lưu đoạn mã này vào nơi an toàn (Zalo cá nhân hoặc Notepad) vì GitHub chỉ hiển thị đoạn mã này đúng 1 lần!

05
Quản Trị Tự Động Bằng AI

Ra Lệnh Cho Gemini Spark Tự Động Cập Nhật Website

Bây giờ bạn không cần biết code nữa! Mỗi khi muốn đăng bài, thêm ảnh hay đổi số điện thoại, chỉ cần nhắn tin cho Gemini Spark.

Dưới đây là mẫu câu lệnh (Prompt) chuẩn để bạn copy và gửi cho Gemini Spark / AI Assistant của bạn:

📋 MẪU CÂU LỆNH (PROMPT) GỬI CHO GEMINI SPARK: 
Chào bạn Gemini Spark,
Tôi muốn bạn đóng vai trò là Quản trị viên website chuyên nghiệp của tôi.
Đây là thông tin kết nối GitHub của tôi:
- GitHub Repository: [ĐIỀN TÊN GITHUB CỦA BẠN/TÊN REPO - Ví dụ: trinhan-ai/Trinh-An-Chia-Se]
- GitHub Token: [DÁN MÃ TOKEN ghp_... CỦA BẠN VÀO ĐÂY]

Hôm nay, hãy giúp tôi cập nhật website với các nội dung sau:
1. Đăng thêm một bài viết mới về chủ đề: "Cách người lớn tuổi ứng dụng ChatGPT viết thư chúc Tết con cháu".
2. Thêm một bức tranh nghệ thuật mới vào kho ảnh: Tiêu đề "Đêm Trăng Bình An", thể loại "Tâm An & Thiền Định".
3. Cập nhật số điện thoại Hotline/Zalo hỗ trợ của tôi thành: 09xx xxx xxx.

Hãy tự động đọc mã nguồn trang web trong file data.js và index.html, sau đó commit và push trực tiếp lên nhánh main giúp tôi. Xin cảm ơn!

💡 Gemini Spark sẽ làm những gì?

Gemini Spark sẽ dùng mã Token bạn cung cấp để mở kho GitHub của bạn, tự động tạo bài viết mới, cập nhật danh sách ảnh, và lưu vào trang web. Chỉ sau 30 giây, khi bạn mở trang web lên là nội dung mới đã xuất hiện đẹp mắt!
