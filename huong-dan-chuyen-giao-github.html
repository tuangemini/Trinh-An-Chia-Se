Phần 1 • Đưa Dữ Liệu Lên GitHub

4 Giải Pháp Chuyển Code Sang GitHub Mới

Tùy theo sự thuận tiện, bạn có thể chọn 1 trong 4 cách dưới đây:

Giải Pháp 1

Bấm nút "Fork" (Nhân bản 1-Click trên Web)

★ Khuyên Dùng Nhất

Khi nào dùng: Khi bạn muốn sao chép toàn bộ website từ kho gốc của người khác sang tài khoản của mình mà không cần tải bất cứ file nào về máy.

Bước 1: Đăng nhập tài khoản GitHub mới của bạn.

Bước 2: Mở link dự án gốc: https://github.com/tuangemini/Trinh-An-Chia-Se

Bước 3: Nhìn lên góc trên cùng bên phải màn hình, bấm vào nút 🍴 Fork.

Bước 4: Bấm nút xanh "Create fork". Trong 3 giây, toàn bộ trang web đã sang tài khoản của bạn chuẩn 100%!

Giải Pháp 2

Kéo Thả Trực Tiếp Từ Máy Tính (Upload Files)

Dễ Hiểu

Khi nào dùng: Khi bạn tạo một kho mới tinh (New Repository) và muốn tải file từ máy tính lên.

⚠️ NGUYÊN TẮC VÀNG: Không bao giờ kéo cả thư mục cha bên ngoài!

Bước 1: Mở thư mục dự án trên máy tính ra (ví dụ mở bên trong thư mục Trinh-An-Chia-Se).

Bước 2: Nhấn tổ hợp phím Ctrl + A để bôi đen toàn bộ các file bên trong: index.html, data.js, admin.js, thư mục images,...

Bước 3: Trên trang GitHub của bạn, bấm Add file ▾ -> Chọn Upload files.

Bước 4: Kéo các file đã chọn thả vào khung vuông trên trình duyệt -> Kéo xuống dưới bấm nút xanh Commit changes.

Giải Pháp 3

Dùng Phím Tắt "." Để Cut / Chuyển File Trực Tiếp Trên Web

Không Cần Upload Lại

Khi nào dùng: Khi bạn lỡ kéo cả thư mục cha lên GitHub khiến tất cả file bị lọt vào thư mục con (như trường hợp Test-TrinhAn/Trinh-An-Chia-Se/...).

Bước 1: Tại trang chính của kho lưu trữ trên GitHub, nhấn phím dấu chấm . trên bàn phím (màn hình sẽ mở trình biên soạn trực quan VS Code for Web).

Bước 2: Ở danh sách bên trái, mở thư mục con ra, giữ phím Shift chọn các file (hoặc kéo từng file như index.html, data.js, thư mục images) kéo thả lên dòng chữ tên kho trên cùng (thư mục gốc).

Bước 3: Chuột phải vào thư mục cũ rỗng -> Chọn Delete để xóa.

Bước 4: Nhìn sang thanh biểu tượng ngoài cùng bên trái, bấm vào biểu tượng Source Control (hình nhánh cây) -> Gõ chữ Chuyen file ra ngoai -> Bấm nút tích xanh Commit & Push.

Giải Pháp 4

Đẩy Bằng Lệnh Git Từ Máy Tính (3 Giây Là Xong)

Chính Xác Tuyệt Đối

Khi nào dùng: Khi máy tính của bạn đã có sẵn thư mục code chuẩn và bạn muốn đẩy đè ngay lập tức lên kho GitHub mới.

Mở cửa sổ dòng lệnh (Terminal / PowerShell) ngay tại thư mục website trên máy tính và copy chạy lệnh sau:

git remote set-url origin https://github.com/TÊN_GITHUB/TÊN_KHO.git & git push -u origin main --force

*(Thay TÊN_GITHUB và TÊN_KHO bằng thông tin tài khoản của bạn)*

Phần 2 • Xuất Bản Online

Bật Tính Năng GitHub Pages Để Trang Web Hoạt Động

Chỉ với vài click chuột, website của bạn sẽ phát sóng trực tuyến miễn phí trọn đời!

1

Tại kho lưu trữ của bạn, bấm vào thẻ ⚙️ Settings (nằm ở thanh menu ngang phía trên cùng).

2

Nhìn sang cột menu bên trái, tìm và bấm vào mục 📄 Pages.

3

Tại mục Build and deployment:

  • Ô Branch (mặc định đang là None ▾): Bấm vào và chọn chữ main.
  • Ô thư mục bên cạnh: Giữ nguyên /(root).
  • Bấm nút Save (Lưu).
🖼️ Minh Họa Màn Hình Settings -> Pages:
Branch: [ main ▼ ] Folder: [ /(root) ▼ ] Save
✓ Your site is live at: https://tên-bạn.github.io/tên-kho/

*(Đợi khoảng 1 đến 2 phút sau khi bấm Save, nhấn F5 tải lại trang sẽ thấy đường link web màu xanh xuất hiện trên đỉnh)*

Phần 3 • Tên Miền Website

Cấu Hình Tên Miền Riêng (Domain) Hoặc Dùng Đuôi Miễn Phí

Hiểu rõ file CNAME để web không bị báo lỗi tên miền.

🌐 Trường Hợp A: Dùng Tên Miền Riêng

Nếu bạn đã mua tên miền (ví dụ: trinhan.life hoặc tenban.vn):

  • Mở file tên là CNAME trên GitHub.
  • Bấm icon cây bút chì ✏️ để sửa, gõ tên miền của bạn vào đó.
  • Trỏ bản ghi DNS tại nhà cung cấp tên miền về GitHub theo hướng dẫn.
🆓 Trường Hợp B: Dùng Link Miễn Phí Của GitHub

Nếu bạn chưa mua tên miền và muốn dùng link miễn phí dạng: https://tên-bạn.github.io/tên-kho/:

  • Bấm vào file CNAME trên GitHub.
  • Bấm vào biểu tượng thùng rác (Delete) để XÓA file CNAME này đi!
  • GitHub sẽ tự động cấp link miễn phí chạy ngay lập tức.
Phần 4 • Tự Quản Trị Trọn Đời

3 Cách Tự Quản Trị Website Dễ Dàng Sau Này

Sau khi website đã lên mạng, bạn có thể tự mình cập nhật bài viết, tranh ảnh theo 3 cách:

🔐

Cách A: Quản Trị Trực Tiếp Trên Giao Diện Web (An Nhiên CMS Studio)

Không cần biết code, có giao diện nhập liệu như Word

Bước 1: Mở Bảng Quản Trị

Trên trang web, bấm vào nút 🔐 Quản Trị ở góc trên thanh menu (hoặc bấm tổ hợp phím Ctrl + Shift + A).

Bước 2: Nhập Mã PIN

Mã PIN bảo mật mặc định là: 1979 (bạn có thể tự đổi mã PIN mới trong cài đặt).

Bước 3: Thêm / Sửa / Xóa

Bấm chọn tab Bài Viết, Kho Tranh, Prompt hoặc Video để sửa. Dữ liệu sẽ cập nhật ngay lập tức!

🤖

Cách B: Ra Lệnh Cho Trợ Lý AI (Gemini Spark) Tự Động Quản Trị

Chỉ cần nhắn tin bằng tiếng Việt là AI tự sửa web giúp bạn

Chuẩn bị mã chìa khóa kết nối (GitHub Token):
Truy cập https://github.com/settings/tokens/new -> Đặt tên token, chọn thời hạn No expiration, tích chọn ô ☑️ repo -> Bấm Generate token và copy đoạn mã ghp_....

📋 MẪU CÂU LỆNH (PROMPT) GỬI CHO GEMINI SPARK: 
Chào bạn Gemini Spark,
Đây là thông tin kho GitHub website của tôi:
- Repository: [TÊN_GITHUB_CỦA_BẠN/TÊN_KHO]
- GitHub Token: [DÁN MÃ TOKEN ghp_... CỦA BẠN VÀO ĐÂY]

Hôm nay hãy giúp tôi cập nhật website:
1. Đăng bài viết mới tiêu đề: "[TIÊU ĐỀ BÀI VIẾT]" thuộc chuyên mục "Thư Viện Học AI".
2. Thêm một bức tranh nghệ thuật mới vào kho ảnh: Tiêu đề "[TÊN TRANH]".
3. Cập nhật số Hotline / Zalo của tôi thành: [SỐ ĐIỆN THOẠI CỦA BẠN].
4. Hãy commit và push trực tiếp lên nhánh main giúp tôi. Cảm ơn bạn!
✏️

Cách C: Sửa Nhanh Bằng Trình Soạn Thảo GitHub (Bút Chì Hoặc Phím ".")

Dành cho việc chỉnh sửa nhanh số điện thoại, link mạng xã hội hoặc đổi chữ

• Sửa 1 file: Bấm vào file data.js trên GitHub -> Bấm icon cây bút chì ✏️ ở góc phải -> Sửa số điện thoại hoặc link YouTube -> Bấm nút xanh Commit changes.

• Sửa nhiều file cùng lúc: Nhấn phím dấu chấm . trên bàn phím để mở giao diện VS Code Web -> Sửa file -> Bấm Source Control -> Commit & Push.

Sổ Tay Xử Lý Sự Cố Thường Gặp (FAQ)

Các câu hỏi thực tế người dùng hay gặp và cách giải quyết trong 1 phút

❓ Hỏi: Tôi lỡ kéo cả thư mục cha lên GitHub nên bị lọt vào thư mục con, website bị lỗi 404 thì làm sao?

👉 Đáp: GitHub Pages chỉ tự động nhận file index.html nằm ở thư mục gốc ngoài cùng (Root). Bạn có 2 cách giải quyết:
• Cách 1: Bấm phím tắt . (dấu chấm) trên bàn phím -> Kéo các file bên trong thư mục con ra ngoài thư mục gốc -> Xóa thư mục cũ đi -> Commit & Push.
• Cách 2: Mở thư mục trên máy tính ra, nhấn Ctrl + A để chọn các file bên trong rồi kéo thả lại vào mục Add file -> Upload files.

❓ Hỏi: Tại sao bấm vào nút "Add a README file" lại thấy trang trống không có file nào?

👉 Đáp: Nút "Add a README file" là tính năng để bạn soạn một văn bản giới thiệu mới cho dự án (giống như trang bìa cuốn sách). Vì kho chưa có file này nên GitHub mở một trang trắng để bạn gõ chữ vào. Đây là bình thường, không phải bị mất file! Để xem danh sách code của bạn, hãy bấm vào chữ <> Code ở góc trên bên trái nhé.

❓ Hỏi: Tôi đã sửa nội dung trên GitHub nhưng mở trang web lên vẫn thấy nội dung cũ?

👉 Đáp: Trình duyệt web của bạn thường lưu lại bản cũ trong bộ nhớ đệm (cache). Hãy nhấn tổ hợp phím Ctrl + F5 (trên Windows) hoặc mở bằng Tab Ẩn Danh (Incognito) trên điện thoại để ép trình duyệt tải phiên bản mới nhất từ GitHub Pages về nhé.

❓ Hỏi: Video YouTube muốn hiển thị trong khung phát thì cần đường link như thế nào?

👉 Đáp: Khung phát video YouTube cần một Mã video ID gồm 11 ký tự (ví dụ: trong link https://www.youtube.com/watch?v=133gUdvBls8 thì mã ID là 133gUdvBls8). Nếu bạn chỉ nhập link kênh (dạng @annhienaimusictta) thì hệ thống sẽ mở kênh YouTube chứ không thể nhúng toàn bộ trang kênh vào trong khung hình được.

Bạn có thể in ra giấy hoặc lưu thành file PDF để dễ dàng đọc lại bất cứ lúc nào.
