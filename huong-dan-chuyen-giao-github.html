🟢 MODULE 1 • DÀNH CHO NGƯỜI MỚI BẮT ĐẦU HOÀN TOÀN

Tạo Tài Khoản & Sở Hữu "Sổ Đỏ Trực Tuyến" GitHub

Thời gian hoàn thành: ~3 phút • Không cần biết kỹ thuật lập trình

💡 Hiểu Đúng & Đơn Giản Về GitHub (Không Lo Sợ Kỹ Thuật):

Nhiều người nghĩ GitHub là thứ gì đó cao siêu của dân công nghệ. Nhưng thực ra, bạn chỉ cần hiểu:
• GitHub giống như một "Két sắt an toàn & Sổ đỏ trực tuyến" do tập đoàn Microsoft sở hữu. Toàn bộ hình ảnh, bài viết, mã nguồn trang web của bạn được cất giữ ở đây trọn đời, không bao giờ bị hack hay mất mát.
• GitHub Pages là tính năng phát sóng miễn phí đi kèm: Giúp bạn biến các file lưu trong két sắt đó thành một trang web sống động trên mạng Internet với chi phí duy trì 0 đồng.

3 Bước Đăng Ký Tài Khoản GitHub Miễn Phí:

1

Mở trình duyệt web và truy cập vào đường link đăng ký chính thức của GitHub:

https://github.com/signup
2

Điền 3 thông tin cơ bản:

  • Email: Nhập địa chỉ Gmail bạn đang dùng hàng ngày.
  • Password (Mật khẩu): Tạo mật khẩu gồm ít nhất 8 ký tự (có chữ và số).
  • Username (Tên người dùng): Đặt tên thương hiệu của bạn viết liền không dấu (ví dụ: annhienai hoặc trinh-an). Tên này sau này sẽ là một phần đường link website miễn phí của bạn!
3

Xác thực Email:

Mở hòm thư Gmail của bạn, lấy mã số 6 chữ số mà GitHub vừa gửi và gõ vào màn hình. Bạn đã có ngay một tài khoản GitHub chính chủ sẵn sàng làm website!

🔵 MODULE 2 • XUẤT BẢN WEBSITE LÊN MẠNG

Đưa Dữ Liệu Lên GitHub & Phát Sóng Trang Web Online

Thời gian hoàn thành: ~5 phút • Có thể dùng con đường 1-click hoặc tải từ máy tính

🛣️ Bài 2.1: Chọn 1 Trong 2 Cách Đưa Code Sang Tài Khoản Của Bạn:

Cách A • Khuyên Dùng Nhất

Bấm Nút "Fork" (Nhân bản 1-Click trên Web)

Không cần tải file về máy tính! Bạn chỉ cần vào link gốc của Tuấn và bấm 1 nút là toàn bộ web được chép sang GitHub của bạn:

https://github.com/tuangemini/Trinh-An-Chia-Se

👉 Nhìn góc trên bên phải, bấm vào nút 🍴 Fork -> bấm nút xanh "Create fork". Xong ngay trong 3 giây!

✓ Nhanh nhất, không lo lỗi nhầm thư mục con
Cách B • Tự Kéo Thả

Kéo Thả Các File Từ Máy Tính Lên Kho Mới

Dành cho khi bạn bấm New repository để tạo kho mới và muốn tải file từ máy lên:

⚠️ NGUYÊN TẮC VÀNG TRÁNH LỖI:

Hãy mở hẳn bên trong thư mục trên máy ra, nhấn Ctrl + A để bôi đen tất cả file bên trong (index.html, data.js, thư mục images,...) rồi kéo thả vào GitHub. Tuyệt đối không kéo cả thư mục cha bên ngoài!

✓ Chủ động đưa bất kỳ phiên bản nào trên máy lên

🚀 Bài 2.2: Kích Hoạt Xuất Bản Website (GitHub Pages):

Tại trang kho lưu trữ của bạn trên GitHub, thực hiện đúng 3 bước nhấp chuột:

Bước 1: Vào Cài Đặt

Bấm vào thẻ ⚙️ Settings ở thanh menu trên cùng.

Bước 2: Mở Mục Pages

Ở cột menu bên trái, tìm và bấm vào chữ 📄 Pages.

Bước 3: Chọn Nhánh & Lưu

Tại Branch: chọn main, thư mục giữ /(root) -> Bấm Save.

* Sau khi bấm Save, đợi khoảng 1 đến 2 phút rồi nhấn F5 tải lại trang, bạn sẽ thấy đường link web màu xanh xuất hiện trên đỉnh!

🌐 Bài 2.3: Cấu Hình Tên Miền Website (File CNAME):

Nếu bạn muốn dùng link MIỄN PHÍ của GitHub:

Link có dạng: https://tên-bạn.github.io/tên-kho/

👉 Việc cần làm: Bấm vào file có tên CNAME trên GitHub -> Bấm icon thùng rác để XÓA file này đi!

Nếu bạn dùng TÊN MIỀN RIÊNG (mua ngoài):

Ví dụ: trinhan.life hoặc tenban.com

👉 Việc cần làm: Mở file CNAME, bấm icon cây bút chì ✏️ để sửa thành tên miền của bạn và trỏ DNS theo hướng dẫn.

🟣 MODULE 3 • TỰ QUẢN TRỊ TRỌN ĐỜI

Tự Cập Nhật Bài Viết, Tranh Ảnh & Đổi Thông Tin Dễ Dàng

Không cần thuê dịch vụ quản trị • Bạn có 3 cách cực kỳ tiện lợi

Cách 1 • Quản Trị Trực Tiếp Trên Web Dễ như dùng Word

An Nhiên CMS Studio (Tích Hợp Sẵn Ngay Trên Website)

Ngay trên website của bạn, bất cứ lúc nào bạn cũng có thể mở Trung tâm Quản trị để thêm bài học, thêm tranh mới, đổi link video:

Bước 1: Mở Quản Trị Bấm nút 🔐 Quản Trị ở menu trên cùng (hoặc bấm phím tắt Ctrl + Shift + A).
Bước 2: Nhập Mã PIN Mã PIN mặc định là: 1979 (có thể đổi mã mới tùy thích).
Bước 3: Nhập Liệu & Lưu Chọn các tab Bài viết, Kho tranh, Video để thêm mới. Dữ liệu sẽ cập nhật ngay trên trang!
Cách 2 • Đỉnh Cao Công Nghệ Tự động hóa 100%

Ra Lệnh Cho Trợ Lý AI (Gemini Spark) Tự Động Quản Trị

Bạn không cần chạm vào code. Chỉ cần tạo một mã GitHub Personal Access Token (chìa khóa kết nối) và gửi câu lệnh bằng tiếng Việt cho Gemini Spark:

1. Lấy mã Token kết nối (Làm 1 lần duy nhất):

https://github.com/settings/tokens/new

* Điền tên token, chọn thời hạn No expiration, tích chọn ô ☑️ repo -> Bấm nút xanh Generate token và lưu đoạn mã ghp_... lại.

📋 MẪU CÂU LỆNH (PROMPT) GỬI CHO GEMINI SPARK: 
Chào bạn Gemini Spark,
Đây là thông tin kho GitHub website của tôi:
- Repository: [TÊN_GITHUB_CỦA_BẠN/TÊN_KHO]
- GitHub Token: [DÁN MÃ TOKEN ghp_... CỦA BẠN VÀO ĐÂY]

Hôm nay hãy giúp tôi cập nhật website với các nội dung sau:
1. Đăng một bài viết mới: Tiêu đề "[TIÊU ĐỀ]", chuyên mục "Thư Viện Học AI".
2. Bổ sung một tác phẩm tranh nghệ thuật mới: Tiêu đề "[TÊN TRANH]".
3. Cập nhật số điện thoại Hotline / Zalo của tôi thành: [SỐ ĐIỆN THOẠI].

Hãy đọc mã nguồn trong data.js và index.html, sau đó commit và push trực tiếp lên nhánh main giúp tôi. Xin cảm ơn!
Cách 3 • Sửa Nhanh

Sửa Trực Tiếp File Trên GitHub Bằng Cây Bút Chì ✏️

Nếu bạn chỉ muốn sửa nhanh 1 thông tin (như đổi số Zalo, đổi link YouTube):
1. Bấm vào file data.js trên GitHub.
2. Bấm vào biểu tượng cây bút chì ✏️ ở góc trên bên phải.
3. Tìm dòng số điện thoại hoặc link YouTube để sửa -> Kéo xuống dưới bấm nút xanh Commit changes. Xong!

🟠 MODULE 4 • CHUYỂN GIAO & NHÂN BẢN DỰ ÁN

Quy Trình Chuyển Giao Trọn Gói Cho Học Viên & Đối Tác

Dành cho khi bạn muốn nhân bản trang web này cho người khác sở hữu

Quy Trình 3 Bước Bàn Giao Nhanh Nhất:

1
Gửi đường link hoặc file zip: Gửi link GitHub kho của bạn và bảo người nhận bấm nút Fork (hoặc gửi file nén TrinhAn-Life-Website.zip).
2
Hướng dẫn bật GitHub Pages: Bảo người nhận vào Settings -> Pages -> chọn Branch main -> Save như ở Module 2.
3
Bàn giao tài khoản quản trị: Cung cấp mã PIN 1979 để họ tự mở giao diện 🔐 Quản Trị và thay đổi tên, hình ảnh, bài viết của chính họ.

✅ Checklist 5 Điểm Cần Kiểm Tra Trước Khi Bàn Giao:

  • Số điện thoại & Zalo: Đã cập nhật đúng số của người sở hữu mới trong file data.js chưa?
  • Kênh YouTube & Mạng xã hội: Đã trỏ đúng link kênh của người nhận chưa?
  • Tên miền (CNAME): Nếu người nhận chưa mua tên miền riêng, đã xóa file CNAME để web không bị báo lỗi chưa?
  • Mã Token bí mật: Không chia sẻ mã Token cá nhân cũ của bạn cho người khác (họ sẽ tự tạo Token riêng của họ).
  • Mã PIN Quản trị: Hướng dẫn họ cách tự đổi mã PIN mới trong cài đặt để bảo mật riêng.
💡 Mẹo: Muốn 2 người cùng quản trị chung 1 website?

Vào kho GitHub của bạn -> Bấm thẻ Settings -> Mục Collaborators (Cộng tác viên) ở cột trái -> Bấm nút xanh Add people -> Gõ tên tài khoản GitHub của người kia và gửi lời mời. Họ chấp nhận là cả 2 cùng sửa web được!

🔴 MODULE 5 • CỨU HỘ SỰ CỐ & SỬA LỖI TRONG 1 PHÚT

Giải Quyết Mọi Trục Trặc Người Dùng Thường Gặp

Hầu hết các lỗi đều có nguyên nhân rất đơn giản và sửa được ngay lập tức

❓ Lỗi 1: Tôi lỡ kéo cả thư mục cha lên GitHub, website bị lỗi 404 (Không tìm thấy trang)?

👉 Nguyên nhân: GitHub Pages chỉ tự động tìm file index.html nằm ở thư mục gốc ngoài cùng (Root). Nếu file index.html bị lọt vào thư mục con (ví dụ: Test-TrinhAn/Trinh-An-Chia-Se/index.html) thì web sẽ không chạy.
👉 Cách sửa siêu tốc (Không cần upload lại):
1. Tại trang kho GitHub của bạn, nhấn phím dấu chấm . trên bàn phím.
2. Giao diện VS Code Web mở ra: Mở thư mục con bên trái, chọn file index.html, data.js, thư mục images... kéo thả thẳng ra ngoài thư mục gốc trên cùng.
3. Chuột phải vào thư mục con rỗng vừa chuyển xong -> Chọn Delete.
4. Bấm biểu tượng Source Control (hình nhánh cây bên trái) -> Gõ chữ lưu -> Bấm nút tích xanh Commit & Push. Xong!

❓ Thắc mắc 2: Tại sao bấm vào nút "Add a README file" lại thấy trang soạn thảo trắng tinh?

👉 Giải thích: File README.md giống như "tờ bìa giới thiệu" cuốn sách. Nút "Add a README file" là tính năng để bạn tạo mới file giới thiệu này từ đầu nên GitHub mở trang trắng để bạn tự gõ chữ. Đây là bình thường, không phải bị mất file!
👉 Cách xem file code của bạn: Chỉ cần bấm vào chữ <> Code ở góc trên bên trái màn hình là sẽ thấy toàn bộ file website của bạn.

❓ Lỗi 3: Tôi đã sửa nội dung trên GitHub nhưng mở trang web lên vẫn thấy nội dung cũ?

👉 Nguyên nhân: Trình duyệt web của bạn đã lưu lại hình ảnh và bài viết cũ vào bộ nhớ đệm (cache) để tải cho nhanh.
👉 Cách sửa: Nhấn tổ hợp phím Ctrl + F5 (trên máy tính Windows) hoặc mở bằng Tab Ẩn Danh (Incognito) trên điện thoại để ép trình duyệt tải ngay bản mới nhất từ GitHub Pages về.

❓ Lỗi 4: Video YouTube trong khung phát không chịu chạy hoặc báo lỗi?

👉 Nguyên nhân: Trình phát video YouTube yêu cầu Mã ID video gồm 11 ký tự (ví dụ: trong link https://www.youtube.com/watch?v=133gUdvBls8 thì mã ID là 133gUdvBls8).
👉 Nếu bạn dán link kênh chung chung (như @annhienaimusictta) thì YouTube sẽ chặn không cho nhúng trong khung hình mà chỉ mở trang kênh thôi. Hãy dán link của một video bài hát cụ thể nhé!
